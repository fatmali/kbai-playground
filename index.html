    Why these connections?

    Lesson 01, p. 7: reasoning, learning, and memory work together as deliberation. Reuse brings stored knowledge into Reason; Learn stores or revises knowledge from examples and outcomes. Memory also supplies knowledge for learning.

    Lesson 24, pp. 315–318: metacognition examines the agent's knowledge, reasoning, and learning. Oversee can trigger a repair, a learning goal, or a strategy change; it is not the next step after Reason.

    Our three-stage pipeline is a teaching view, not the course's full cognitive architecture. Represent is how knowledge is organized, not a separate replacement for memory. Roles overlap; these arrows show the main connections, not every possible one.

    How the sections connect · Course lesson map

    These sections are a teaching view, not the course's official units or a required execution order. A method can serve more than one role. These are fixed walkthroughs: Next reveals the next state and code fragment; it does not execute Python or connect examples into one running agent. The URL saves the selected section and topic; walkthrough steps restart on reload.

    On desktop, read the notes beside the playground on the right. On smaller screens, use the Notes and Playground tabs above. Switching tabs keeps your current step and pauses playback when the playground is hidden.

    1. Perceive interprets input; Represent organizes knowledge; Reason uses that knowledge to find an answer. Interpretation itself can involve reasoning in the course's broader sense.
    2. Memory stores and supplies knowledge. Reuse feeds it into Reason; Learn updates it from examples, explanations, or results. The course calls reasoning, memory, and learning together deliberation (L01, p. 7).
    3. Oversee is the meta-level: monitor knowledge, reasoning, and learning, then repair or redirect them (L24, pp. 315–318). Learning by Correcting Mistakes belongs here and also changes knowledge; L23 introduces it as the first meta-reasoning lesson (p. 304).
    4. Classification now sits under Perceive because this example maps observed features to a known concept (L11, p. 136), rather than learning that concept. Diagnosis sits under Reason because this example infers faults in an external system (L22, p. 292); diagnosing the agent's own reasoning is meta-reasoning.
    5. Ethics applies to design and use across the agent. It is not an automatic runtime feedback step (L25, pp. 340–341).

    Placement is not exclusive: recording cases is both learning and a basis for analogy (L08, p. 93). Case-Based Reasoning spans retrieval, adaptation, evaluation, and storage (L09, p. 101); its walkthrough starts from reuse, but also reasons and learns.

    One possible combination: identify shapes → encode a semantic network → generate and test transformations → record a useful solution → switch to a visual method if the symbolic model misses a pattern. You do not need every tool.
